# SANG — портал заявок

Русскоязычный адаптивный сайт с главной страницей SANG, карточками High Staff онлайн, четырьмя формами заявлений, входом через Discord и отправкой заявок в Discord.

## Запуск локально

Требуется Node.js 22.4 или новее. Скопируйте `.env.example` в `.env`, заполните настройки ниже и запустите сайт:

```powershell
Copy-Item .env.example .env
node --env-file=.env server.mjs
```

Затем откройте `http://localhost:3000`. npm-пакеты не требуются.

## Настройка Discord

1. В [Discord Developer Portal](https://discord.com/developers/applications) создайте приложение. В разделе **OAuth2 → General** скопируйте Client ID и Client Secret в `DISCORD_CLIENT_ID` и `DISCORD_CLIENT_SECRET`.
2. В **OAuth2 → Redirects** добавьте адрес `http://localhost:3000/auth/discord/callback`. Для размещённого сайта добавьте точный HTTPS адрес callback и укажите его в `DISCORD_REDIRECT_URI`.
3. В нужном Discord канале создайте webhook через **Настройки канала → Интеграции → Вебхуки**, скопируйте URL в `DISCORD_WEBHOOK_URL`. Это отправляет красиво оформленные заявки от имени интеграции; отдельный Discord-бот не нужен.
4. Создайте Discord-бота в Developer Portal и добавьте его на сервер. Включите для него **Server Members Intent** и **Presence Intent**. Задайте сервер ID и bot token в `DISCORD_GUILD_ID` и `DISCORD_BOT_TOKEN`. Укажите ID роли **High Staff** в `HIGH_STAFF_ROLE_ID`: бот получает статусы участников через Discord Gateway, а сайт показывает тех, кто сейчас online, idle или Do Not Disturb. Этот же ID используется для проверки доступа High Staff к модерации заявок.
5. Создайте длинный случайный секрет для `SESSION_SECRET`. На локальной машине с HTTP оставьте `COOKIE_SECURE=false`. В production используйте HTTPS, установите `COOKIE_SECURE=true` и храните секреты только в переменных окружения платформы.

Участники с Discord ролью **High Staff** видят вкладку проверки заявок. Они могут раскрыть ответы и одобрить или отклонить заявку. Решение обновляет сообщение исходной заявки в Discord и отражается в истории профиля автора. Все пользователи видят только собственную историю.

Заявки принимаются только после входа через Discord. Профили и заявки хранятся в JSON-файлах каталога `data/` рядом с сервером; для размещения на платформе с временным диском подключите постоянный том хранения. Секреты и webhook URL используются только сервером и не встраиваются в страницу. Для публичного запуска дополнительно подключите HTTPS-хостинг и ограничение частоты запросов по требованиям вашего сообщества.

## Что настроить под свою фракцию

В `index.html` замените демонстрационные названия подразделений и при необходимости отредактируйте массивы `units` и `types`: перечень отделов в формах и поля заявлений. Сейчас доступны трудоустройство, перевод, восстановление и снятие ЧС.
